3. Backup

The database is stored on the server (directory set by the DATA_DIR variable). On Railway it survives a redeploy only if a Volume is attached and DATA_DIR points to its mount path. Otherwise, export the data and commit the file as volcano_deformation_seed.json in the repository root; it is loaded automatically whenever the database is empty. Import replaces ALL existing entries.
